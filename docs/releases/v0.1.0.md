# Truepane v0.1.0 — First public release

Truepane turns raw app captures into store-ready App Store and Google Play screenshot sets. Use the visual browser editor, hand the workflow to an MCP-capable coding agent, or move the same editable project between both.

## Highlights

- Exact native output for iPhone 6.9″, iPad 13″, Android phone, and Android tablet
- Local canvas rendering: screenshots stay on your machine
- Flexible text and device composition, including flat rotation and cross-slide devices
- Seeded procedural backgrounds with fills, shapes, palette extraction, and reusable brand kits
- Multi-target and per-locale screenshots, copy, and fonts in one project
- Preview-first folder and ZIP import with conflict detection
- Shared release preflight for missing assets, fallbacks, fonts, crop risk, composition, and contrast
- Release baselines and changed-only exports
- PNG, strip, ZIP, and editable JSON project export

## Truepane MCP

The repository also ships `truepane-mcp`, currently published separately on npm as version 0.1.10. It lets Codex, Claude Code, and other MCP-capable clients compose, localize, validate, compare, and render projects locally.

```sh
npx -y truepane-mcp
```

The MCP server requires no API key or Truepane account. Source screenshots are read from local paths and rendered PNGs are written to the output directory you choose.

## Notes

- This release focuses on flat, store-submission screenshots. Perspective and photographic device mockups are intentionally out of scope.
- Google Fonts may load from Google's CDN unless you use a system or uploaded font.
- Optional browser AI helpers are separate from the local MCP workflow and remain opt-in.
- Preflight warnings are advisory and can be intentionally overridden.
