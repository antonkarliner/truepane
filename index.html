Browser-based screenshot generator

Create App Store and Google Play screenshots with Truepane

Truepane helps indie app builders turn product screenshots into store-ready screenshot sets. Add title and subtitle text, choose an iPhone, iPad, Android phone, or Android tablet frame, style a procedural background, and export individual PNGs, one horizontal strip, or a ZIP.

Store-sized frames

Generate screenshots for App Store and Google Play formats, including iPhone 6.9 inch, iPad 13 inch, Android phone, and Android tablet.

Local canvas rendering

Screenshots are rendered in the browser. Uploaded app images stay on your device and are not sent to a server by the generator.

Export options

Download a single slide PNG, a horizontal screenshot strip, a ZIP of all slides, or a JSON project file for later editing.

Optional AI styling

When configured, the AI prompt helper can turn a short style prompt into background and palette settings. The app still works without it.

For AI agents · MCP

Let an AI agent build your screenshots

Truepane ships an open-source Model Context Protocol server, so coding agents like Claude Code, Codex, and Cursor can frame raw simulator screenshots, style them, localize the text (including right-to-left scripts such as Arabic), and render store-ready PNGs — no browser needed. It runs locally and needs no API keys.

FAQ

What is Truepane?

Truepane is a browser app for making App Store and Google Play screenshot sets with device frames, text overlays, generated backgrounds, and export tools.

Does Truepane upload my app screenshots?

No. Screenshot composition happens locally on canvas in your browser. The optional AI style helper only sends the text prompt when that feature is configured and used.

Can I export screenshots for both App Store and Google Play?

Yes. Truepane includes Apple and Android device formats and exports slide PNGs, horizontal strips, ZIP files, and JSON project backups.

Can AI agents use Truepane?

Yes. Truepane publishes a local Model Context Protocol (MCP) server, truepane-mcp, that any MCP client (Claude Code, Codex, Cursor, and others) can run with npx -y truepane-mcp. An agent can create a project from local screenshots, style it, translate the copy into other languages, and render store-ready PNGs — no API keys required. Projects round-trip with this web app via Import/Export.
