For AI agents · MCP

Build the same project without opening a browser.

The open-source Model Context Protocol server lets Codex, Claude Code, and other compatible agents frame screenshots, style sets, localize copy, and render store-ready PNGs locally.

Quick answers

Good to know

Does Truepane upload my screenshots?

No. Screenshot composition happens locally in your browser.

Can projects move between MCP and the editor?

Yes. Export and import the same editable JSON project in either direction.

Does it support both app stores?

Yes. Apple and Android phone and tablet formats are included.
