For AI agents · MCP

Give your agent the complete release workflow.

The open-source Model Context Protocol server lets Codex, Claude Code, and other compatible agents bulk-import captures, compose and localize sets, run preflight, manage release baselines, and render native or custom outputs locally.

Codex 
codex mcp add truepane -- npx -y truepane-mcp
Claude Code

Quick answers

Good to know

Does Truepane upload my screenshots?

No. Screenshot composition happens locally in your browser.

Can projects move between MCP and the editor?

Yes. Export and import the same editable JSON project in either direction.

Does it support both app stores?

Yes. Apple and Android phone and tablet formats are included, along with the Google Play feature graphic and bounded custom outputs.

Can one device continue across two slides?

Yes. Linked halves share their screenshot, position, scale, and rotation, so the exported slides meet cleanly.
